প্রকৃতির রূপ — Flutter Android starter project

এই ZIP-এ একটি প্রাথমিক Android-compatible Flutter project আছে।
এটি এখনো সম্পূর্ণ Facebook-এর মতো অ্যাপ নয়: বাস্তব লগইন, সার্ভার, পোস্ট সংরক্ষণ,
ছবি আপলোড, বন্ধু/চ্যাট এবং নোটিফিকেশন যুক্ত করা হয়নি।

GitHub-এ ZIP extract করে ভেতরের সব ফাইল ও ফোল্ডার রিপোজিটরির root-এ upload করতে হবে।
শুধু ZIP ফাইলটি upload করলে Codemagic project root খুঁজে পাবে না।
